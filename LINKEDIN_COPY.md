## LinkedIn Project Entry

**Project name**

My_GPT — GPT-Style Language Model from Scratch

**Description**

Implemented a decoder-only GPT-style language model from scratch using PyTorch to understand the internal mechanics of transformer-based LLMs.

• Built token and positional embeddings  
• Implemented Query, Key, and Value projections  
• Implemented scaled dot-product self-attention  
• Added causal masking for autoregressive language modeling  
• Built multi-head attention and transformer blocks  
• Implemented feed-forward layers, residual connections, and normalization  
• Trained the model using cross-entropy loss and AdamW  
• Added evaluation and autoregressive text generation  
• Saved experiment logs, generated samples, and model checkpoints

## LinkedIn Post

🚀 **I built a GPT-style language model from scratch with PyTorch**

One of the best ways I’ve found to understand Large Language Models is to move below the API layer and implement the core architecture directly.

In this project, I built a small decoder-only GPT-style transformer step by step, including:

• Tokenization and vocabulary handling  
• Token + positional embeddings  
• Query, Key, and Value projections  
• Causal self-attention  
• Multi-head attention  
• Transformer blocks  
• Feed-forward networks and residual connections  
• Cross-entropy language-model training  
• AdamW optimization  
• Evaluation and autoregressive text generation  

The goal was not to build a production-scale LLM. It was to understand how the pieces behind GPT actually connect and behave in code.

The repository also includes experiment logs, generated text samples, and a saved model checkpoint.
